# SOP：大客車租賃安全檢核與乘車管理 (Bus Rental Safety & In-Transit Management SOP)

## 1. 法源依據與核心原則
野外實察營隊之長途行車安全為所有活動之基石。麗山高中生物科嚴格依循教育部頒布之《學校辦理校外教學活動租用車輛應行注意事項》，落實**「車輛合規、司機合格、乘車落實安全演練」**三大原則，徹底杜絕拼裝車、過度疲勞駕駛與安全設施失靈之風險。

---

## 2. 租賃前車輛資格審查規範 (T-20 天)

在進行租賃招標或簽約時，必須要求遊覽車客運業者提供下列證明文件並列入契約附件：
1. **車齡要求**：出廠年份距出隊日**不得超過 5 年**（高山山區路線如太平山，強制規定車齡不得超過 3 年之優質車輛）。
2. **車籍與定檢證明**：具備公路監理機關檢驗合格且在有效期限內之「遊覽車行車執照」影本。
3. **強制與任意責任險**：每名乘客投保強制汽車責任險及乘客責任險（每人保額至少 300 萬元以上）。
4. **駕駛人資格**：
   - 具備有效之「職業大客車駕駛執照」及「遊覽車駕駛人登記證」。
   - 具備最近 2 年內無重大交通違規（闖紅燈、超速 20 公里以上、酒駕）與無重大肇事紀錄證明。

## 3. 出發當日清晨現場檢核表 (T-0 出車前 30 分鐘)

出發前，帶隊領隊教師必須會同學校隨隊行政或教官，手持**《校外教學車輛安全檢驗表》**逐項實車查驗：

```

│             出發前大客車安全檢驗必查 6 大項目            │
├───────┬────────────────────────────────────────────────┤
│ 項目1 │ 駕駛資格核對：駕照、遊覽車登記證本尊與酒測 0 檢測。│
│ 項目2 │ 輪胎檢視：輪胎胎紋深度至少 1.6mm 以上（無磨平）， │
│       │ 嚴禁使用翻紋胎（再生胎）。                      │
│ 項目3 │ 安全門測試：車身中後段安全門由內外均能順暢推開，   │
│       │ 通道通道暢通、嚴禁堆放行李或加裝暗鎖。          │
```

## 4. 行車安全與生活常規管理
1. **全員繫緊安全帶**：車輛啟動前，各組安全長逐排檢查，確認每位學生與教師全程繫妥安全帶。
2. **逃生影片與實地演練**：上車後 10 分鐘內，隨車播放公路總局逃生宣導影片，並由領隊教師現場示範車窗擊破器敲擊車窗四角之操作要領。
3. **司機駕駛工時監控**：
   - 每日工時不得超過 10 小時（連續駕車每 4 小時必須強制休息至少 30 分鐘）。
   - 山區長途實察（如宜蘭至太平山）若路途險峻，安排專任副駕駛或確保充分中途停歇。
4. **車內紀律維護**：車輛行駛中嚴禁學生站立走動、打鬧或跨越走道；車內保持安靜，確保司機能專注路況與聆聽警報。
