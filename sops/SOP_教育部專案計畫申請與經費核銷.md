# SOP：教育部專案計畫申請與經費核銷 (Grant Application & Budget Reimbursement SOP)

麗山高中生物營隊長年獲得教育部高中優質化輔助方案、領先計畫、前瞻基礎建設計畫及海保署專案補助。本 SOP 系統梳理專案計畫經費之「預算科目編列準則、憑證核銷標準與結案備查作業」。

---

## 1. 常見專案預算科目編列與核銷標準

依據教育部補（捐）助及委辦經費核撥結報作業要點，生物營隊常用六大預算科目與核銷必備文件：

| 預算科目 | 編列標準與上限說明 | 核銷必備憑證與檢附附件 | 常見退件地雷 |
| :--- | :--- | :--- | :--- |
| **講座鐘點費** | • 外聘專家學者：每節 1,600~2,000 元<br>• 內聘校內教師：每節 800~1,000 元<br>• 課外週末營隊可依規定報支鐘點 | • 領據（載明身分證字號、戶籍地址、金融帳號）<br>• 課程表與簽到退記錄表<br>• 授課現場高解析度照片 | • 未簽到退或時間與課程表衝突<br>• 簽章處以影印代替簽名 |
| **大客車車資 (交通租車費)** | • 依市場行情招標，每日每車約 12,000 ~ 16,000 元（含司機小費與保險） | • 車公司統一發票（三聯式載明學校統編）<br>• 租賃契約書副本<br>• 租賃車輛安全檢核表（逐項勾稽合格） | • 發票買受人統編錯誤<br>• 缺車輛行照或司機駕照影本 |
| **膳費 (便當/合菜)** | • 學生與隨隊教師每日每餐 80 ~ 100 元，合菜每桌 2,500 ~ 3,500 元 | • 餐廳統一發票或免用統一發票收據（附菜單明細）<br>• 用餐人員名冊 | • 發票未列詳細菜單或單價<br>• 用餐人數超過核定名冊 |
| **住宿費** | • 學生每人每日約 600~800 元，教師每人每日依日支標準約 1,400~1,800 元 | • 合法旅宿業專用發票<br>• 入住人員房間配置清冊 | • 選擇未立案民宿<br>• 未列入住人員明細 |
| **材料與印刷費** | • 活動手冊印製（單色/彩色）、採樣標本瓶、水質測試包、防水筆記本 | • 印刷廠/文具行發票（附估價單）<br>• 手冊樣書 1 本送主計室存查 | • 品名僅寫「一批」而無單價明細<br>• 超過政府採購小額採購限額（15萬元） |
| **保險費** | • 師生旅行平安險（含意外死亡失能 200~300 萬、意外醫療 10~20 萬） | • 保險公司正式保險單收據<br>• 被保險人員名冊正本（蓋保險公司章戳） | • 保險期間未涵蓋集合至解散全時段 |

## 2. 經費核銷標準流程與甘特圖

```
[營隊活動結束 T+0]
   └── 3 天內向合作廠商收齊全數統一發票與領據
[整理憑證 T+5]
   └── 黏貼憑證用紙，加蓋經辦人章、生物科召集人章
[行政會核 T+7]
   └── 依序陳送：主辦處室(教務處/學務處/圖書館) → 總務處事務組 → 主計室審核
[校長決行 T+10]
   └── 呈校長批示決行後，主計室開立傳票，出納組撥款入受款人帳戶
[結案報部 T+14]
   └── 彙整「成果報告書 (PDF)」與「經費收支結算表」，上傳教育部專案平台備查
```

## 3. 防退件三大黃金檢核法
1. **抬頭與統編檢驗**：買受人必須完整填寫「臺北市立麗山高級中學」，統一編號必須精確無誤。
2. **名冊實名對應**：所有餐費、保險費、門票費之請購人數，必須等於「活動手冊學生名冊 + 隨隊教師名冊」，嚴禁虛報。
3. **成果照片佐證律**：核銷每筆鐘點費或活動費，必須在結報報告書中檢附對應時段之清晰照片（含解說員身影、學生專注聽講或野外採集畫面），作為具體執行事證。
