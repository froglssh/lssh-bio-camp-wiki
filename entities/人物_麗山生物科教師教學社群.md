# 人物：麗山生物科教師教學社群 (LSSH Biology Faculty PLC)

## 1. 社群組織與運作背景
麗山高中生物科為全臺灣少數長年保持高度緊密凝聚力與開創性的**教師專業學習社群 (Professional Learning Community, PLC)**。面對跨學年的生物營隊、野外實察、專題研究指導與 108 課綱彈性學習課程，團隊摒棄傳統高中教師單打獨鬥的備課模式，採取「學習共同體、專長互補、全員帶隊」的團隊作戰模式。

## 3. 社群長期成功之四大制度化保障
1. **固定每週共同備課時間**：利用每週固定的教學研究會與空堂，滾動修訂營隊行程表、活動手冊學習單與評分規準。
2. **跨專長輪流授課**：在 80 小時長程培育中，依每位老師專長排課，避免單一教師過勞，同時讓學生接觸到多元的生物學視角。
3. **全員週末輪流或共同出隊**：在多日野外考察中全員出動，建立「隨隊指揮、安全督導、學術指導」三位一體之安全防護網。
4. **教研成果學術沉澱**：持續將教學現場的感動與數據，轉化為臺北市教育創新與行動研究得獎論文，實現「教學、實踐、研究、推廣」之良性循環。
