# 紀實：106 學年度・前瞻整合與80小時完整體系 (Forward-looking 80-Hour Architecture)

## 1. 年度背景與核心突破
- **專案依據**：教育部「前瞻基礎建設計畫面向一：高級中等學校校園數位建設與特色課程推動——公民科學家與保育解說員培訓課程」。
- **主持團隊**：林獻升、郭瓊華、蕭國偉、白瓊如等麗山高中生物科教學團隊。
- **年度里程碑**：
  - 106 學年度為麗山生物營隊發展史上**規格最高、體系最完整、跨度最長**的巔峰之年。
  - 團隊整合先前 5 年的所有經驗，正式架構起**「橫跨一整學年、四大模組、累積 80 小時」**的公民科學培育全景體系。

---

## 2. 80 小時四大模組實施全景

```
┌────────────────────────────────────────────────────────┐
│            106 學年度前瞻基礎建設四大活動模組全景        │
├───────┬────────────────────────────────────────────────┤
│ 模組1 │ 環境教育研討講座（室內 20 堂，105/12/10-11）     │
│ 模組2 │ 生態考察營隊活動（校外 20 堂，106/04/08-09）     │
│ 模組3 │ 解說志工培訓活動（現場 18 堂，106/07/01）       │
│ 模組4 │ 公民科學培訓活動（研究與發表 18 堂，106學年度整年│
└───────┴────────────────────────────────────────────────┘
```

### (1) 模組一：密集研討講座（20 堂）
利用連續兩天週末，由 5 位生物老師針對臺灣生態環境、地景地質、調查方法、多樣性與標本倫理進行高強度密集傳授，並導入基礎口語解說演練。

### (2) 模組二：兩天一夜北海岸與東北角野外實察（20 堂）
- **Day 1**：三生櫻花步道 → 白沙灣 → 石門富貴角風稜石與老梅綠石槽 → 阿里磅生態農場（日間次生林導覽 + 夜間蛙類與昆蟲生態調查）→ 夜宿緹閣休閒溫泉會館。
- **Day 2**：舊草嶺隧道自行車踏查 → 福隆遊客中心 → 馬岡海蝕平台潮間帶採集 → 三貂角燈塔 → 田寮洋濕地賞鳥。

### (3) 模組三：基隆海科館與潮境解說考核（18 堂）
- 參訪海科館主題館與潮境海洋中心後場繁養殖基地。
- 全體學生於潮境公園沿線站點，進行現場一對一實地定點口語導覽驗收。

### (4) 模組四：公民科學專案與海報發表（18 堂）
- 回到校園進行金面山森林與生態池長期監測。
- 學生分組完成高規格 A0 學術海報，舉行校內外公開成果發表會。

## 3. 歷史成就與直接影響
- 本年度完整的文字教案、照片紀錄、量化問卷與教學反思，為翌年（107 學年度）榮獲**臺北市第 19 屆行動研究特優雙料大獎**提供了最堅實的原創事實與數據支撐。
