# 紀實：103 學年度・路線擴展與海報發表期 (Route Expansion & Poster Era)

## 1. 年度背景與核心突破
- **專案依據**：教育部高中優質化輔助方案子計畫「D-1-1：自然生態考察與解說員培訓計畫」。
- **主辦承辦**：麗山高中圖書館主辦、生物科教學團隊承辦。
- **年度里程碑**：103 學年度為麗山生物營隊發展史上**極具爆發力的一年**，教師團隊一口氣開闢四大跨生態系實察路線，並全面確立「活動手冊標準版」、「小組 A0 學術海報輸出」與「大講堂公開發表答辯」三大核心制度。

## 2. 歷屆四大經典實察路線全景

```
┌────────────────────────────────────────────────────────┐
│            103 學年度四大自然生態考察戰役全景           │
├───────┬────────────────────────────────────────────────┤
│ 戰役1 │ 103 基隆海洋考察（海科館、潮境公園、八斗子）     │
│ 戰役2 │ 103 宜蘭山區生態考察（雙連埤、福山植物園、仁山）│
│ 戰役3 │ 103 宜蘭賞鳥考察（時潮休閒農業區、塭底水鳥保護區│
│ 戰役4 │ 103 三峽森林生物資源探究（滿月圓、插天山森林）  │
└───────┴────────────────────────────────────────────────┘
```

### (1) 基隆海洋考察：海科館與潮境初探
- 參訪甫落成之國立海洋科技博物館，結合潮境海灣資源保育區潮池觀察，學生首度學習海洋生物分類與海洋酸化議題。

### (2) 宜蘭山區考察：雙連埤水生植物諾亞方舟
- 探訪宜蘭員山雙連埤天然草毯浮島，觀察蓴菜與水社柳等瀕危水生植物，夜宿礁溪進行水生昆蟲採集。

### (3) 宜蘭時潮塭底賞鳥考察：單筒望遠鏡大軍
- 由郭瓊華老師領軍，引進專業高倍率單筒望遠鏡，在時潮魚塭泥灘精準捕捉反嘴鴴、高蹺鴴與度冬雁鴨，創下單日辨識 42 種鳥類之紀錄。

### (4) 三峽森林資源考察：中低海拔闊葉林與溪流
- 深入三峽滿月圓森林遊樂區，調查蚋仔溪水生昆蟲（石蠅、蜉蝣、石蠶）對水質耐受度之指標意義。

## 3. 首屆「成果發表會與學術海報」體系成形
- 103 學年度產出四批經典大型學術海報（均留存於 `歷屆資料整理/103/`）：
  - 《103基隆考察成果發表會海報》
  - 《103宜蘭考察成果發表會海報》
  - 《103宜蘭賞鳥成果發表會海報》
  - 《103三峽考察成果發表會海報》
- 正式宣告麗山生物營隊脫離「郊遊休閒」範疇，全面晉升為具備學術嚴謹度之「高中生態田野工作坊」。
